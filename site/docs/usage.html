Using the app

Open a repository from the dashboard (recent repositories), the folder picker, or by passing its path on the command line.

Browsing history

  • The revision grid shows the commit graph, ref labels (local branches, remote branches, tags), author, date and message. Use the filter and search boxes to narrow it down.
  • Select a commit to see its details, its diff and its file tree. A sidebar tree lists branches, tags, remotes and stashes.
  • History is limited to the most recent 2000 commits by default; raise the limit in Settings. See Troubleshooting.

Committing

  • The commit window stages and unstages whole files, hunks or single lines.
  • It supports amend, sign-off, commit message templates and recent messages.

Diff, blame and file history

The diff viewer works on revisions and on the working tree. The file history window follows renames and can show blame for each line.

Branches, tags, remotes, stashes

Manage branches, tags, remotes and stashes from the sidebar and the context menus. Submodules and linked worktrees have their own dialogs.

History operations

Merge, rebase, cherry-pick, bisect, reset, clean and archive are available for commits and refs. Patches can be formatted, applied and viewed. The merge conflict resolver lets you resolve conflicts without leaving the app.

Clone, init, pull and push

Dedicated dialogs cover clone, init, pull and push. When Git needs a password, passphrase or username, an in-window prompt appears: a small helper (GitExtensions.AskPass) is registered as GIT_ASKPASS / SSH_ASKPASS and relays the question to the app. To avoid typing credentials repeatedly, configure a Git credential helper or an SSH key and agent.

Settings and themes

The settings dialog covers the common options (general, confirmations, colors, Git config, SSH, scripts and more). The theme follows the system or can be set to light or dark.

Keyboard shortcuts and diagnostics

  • The Help menu has a Keyboard shortcuts entry with the shortcut list.
  • The command log shows the Git commands the app ran, and the reflog browser shows ref history.
