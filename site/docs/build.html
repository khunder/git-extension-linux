Build and package

Requirements: the .NET 11 SDK and git. The same commands work on Linux and Windows.

Build and run

git clone https://github.com/khunder/git-extension-linux.git
cd git-extension-linux
dotnet build GitExtensions.slnx
dotnet run --project src/app/GitExtensions.Avalonia -- <repo path>

Tests

dotnet test GitExtensions.slnx

The Avalonia UI tests run headless (no display needed) and use real temporary Git repositories. The render tests also write the screenshots used on this website.

Linux packages

Produced by the scripts in packaging/linux; see its README for details.

packaging/linux/build-tarball.sh                  # linux-x64
RID=linux-arm64 packaging/linux/build-tarball.sh  # linux-arm64

Windows zip and installer

Needs PowerShell 7. The installer step also needs Inno Setup 6; without it only the zip is built.

pwsh packaging/windows/build.ps1 -Arch x64    # or arm64; add -SkipInstaller for the zip only

Output goes to artifacts/dist: git-extensions-windows-<version>-<arch>.zip and git-extensions-<version>-windows-<arch>-setup.exe.

Releases

Pushing a tag v<version> (or running the Release workflow manually) builds every package, smoke-tests them (clean Linux images and a Windows runner), writes SHA256SUMS and creates the GitHub release.
