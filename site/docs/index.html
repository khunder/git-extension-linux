Overview

Git Extensions Next is a graphical Git client for Linux and Windows. It is a port of Git Extensions: the portable core that runs Git and parses its output is kept, and the WinForms interface is replaced by a new one built with Avalonia on .NET 11.

Install

Windows installer and zip, .deb, .rpm, Arch package, AppImage and tarball.

Using the app

History, commit window, branches, merges, remotes and settings.

Build and package

Build from source, run the tests, produce the release artifacts.

Troubleshooting

History stops at 2000 commits, credentials, AppImage and Windows warnings.

Requirements

  • git installed and on the PATH (on Windows: Git for Windows).
  • Nothing else for the released packages: they are self-contained and bundle the .NET runtime.
  • Linux: x64 or arm64. Windows: 10 or 11, x64 or arm64. There are no macOS builds.

Status

This is an early release (0.7.0). Linux is the primary, best-tested platform; the Windows builds are new. Not available yet: plugins (the interfaces are kept but plugins are not loaded), scripts, the hotkeys editor, build server integration, and some less common settings pages and dialogs.

Report problems on the issue tracker.
