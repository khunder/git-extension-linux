Troubleshooting

The history stops after 2000 commits

The revision grid loads at most 2000 commits by default (git log --max-count=2000). Raise the history limit in the settings (up to 1,000,000) and reopen the repository.

Authentication fails or nothing asks for a password

Git Extensions Next shows an in-window prompt when Git asks for credentials through the askpass helper. Some setups never ask (for example SSH with a key that has no agent). Configure a Git credential helper or an SSH key with an agent, then retry from a terminal to confirm Git itself can reach the remote.

The AppImage does not start

Make it executable (chmod +x). If your system has no FUSE 2, run it with --appimage-extract-and-run.

Windows warns about an unknown publisher

The Windows builds are not code-signed yet. Choose "More info", then "Run anyway", after checking the download against SHA256SUMS.

"git" is not found

Install Git (Git for Windows on Windows, your distribution's git package on Linux) and make sure it is on the PATH, then restart the app.

The app refuses to start when built from source

If the message says the framework Microsoft.NETCore.App 11.0.0 is missing while only a release candidate is installed, install the final .NET 11 runtime. The released packages are self-contained and do not need a runtime.

Still stuck?

Open an issue on GitHub with your OS, the app version (About dialog) and, if possible, the relevant lines of the command log.
