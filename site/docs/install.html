Install

All packages are self-contained: no .NET runtime is needed, only git. Every file is attached to the GitHub release together with a SHA256SUMS file.

Windows

Windows 10 and 11, x64 and arm64. Install Git for Windows first.

  • Installer: git-extensions-0.7.0-windows-x64-setup.exe (or arm64). It installs for the current user by default and needs no administrator rights; choose "for all users" when prompted to install system-wide. It adds a Start menu entry, an optional desktop shortcut and an uninstaller.
  • Portable zip: git-extensions-windows-0.7.0-x64.zip (or arm64). Unzip anywhere and run GitExtensions.Avalonia.exe.

The builds are not code-signed, so Windows SmartScreen may warn on first run. Choose "More info", then "Run anyway". Verify the file against SHA256SUMS first if in doubt:

Get-FileHash .\git-extensions-0.7.0-windows-x64-setup.exe -Algorithm SHA256

To open a repository from a terminal: GitExtensions.Avalonia.exe C:\path\to\repository.

Ubuntu and Debian

git-extensions_0.7.0_amd64.deb and git-extensions_0.7.0_arm64.deb.

curl -LO https://github.com/khunder/git-extensions-next/releases/download/v0.7.0/git-extensions_0.7.0_amd64.deb
sudo apt install ./git-extensions_0.7.0_amd64.deb
sudo apt remove git-extensions

Fedora

git-extensions-0.7.0-1.fedora.x86_64.rpm (also .aarch64.rpm).

sudo dnf install ./git-extensions-0.7.0-1.fedora.x86_64.rpm
sudo dnf remove git-extensions

openSUSE

git-extensions-0.7.0-1.opensuse.x86_64.rpm (also .aarch64.rpm). The packages are not signed.

sudo zypper --no-gpg-checks install ./git-extensions-0.7.0-1.opensuse.x86_64.rpm

On newer zypper: sudo zypper install --allow-unsigned-rpm ./git-extensions-...rpm.

Arch Linux

git-extensions-0.7.0-1-x86_64.pkg.tar.zst.

sudo pacman -U ./git-extensions-0.7.0-1-x86_64.pkg.tar.zst
sudo pacman -R git-extensions

AppImage

A portable single file; nothing is installed. git-extensions-0.7.0-x86_64.AppImage and git-extensions-0.7.0-aarch64.AppImage.

chmod +x git-extensions-0.7.0-x86_64.AppImage
./git-extensions-0.7.0-x86_64.AppImage [path-to-repository]

Without FUSE 2 installed, run it with --appimage-extract-and-run.

Any other distribution (tarball)

git-extensions-linux-0.7.0-x64.tar.gz (also -arm64.tar.gz). No root needed: it installs under ~/.local.

tar xzf git-extensions-linux-0.7.0-x64.tar.gz
cd git-extensions
./install.sh
./install.sh --uninstall

Verify a download

curl -LO https://github.com/khunder/git-extensions-next/releases/download/v0.7.0/SHA256SUMS
sha256sum --check --ignore-missing SHA256SUMS

Run

Start "Git Extensions Next" from the application menu, or from a terminal on Linux: git-extensions [path/to/repository].

The Linux packages install the app under /opt/git-extensions, a launcher at /usr/bin/git-extensions, a desktop entry and icons. They depend on glibc, libstdc++, zlib, OpenSSL 3, the usual X11 libraries, fontconfig, FreeType and libpng; openssh-client is recommended for SSH remotes.
